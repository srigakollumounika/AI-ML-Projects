# 🚀 Featured Project

<div align="center">

## 🩺 Diabetes Prediction

### Predicting Diabetes Using Machine Learning

</div>

| 🔹 | Details |
|---|---|
| **Problem** | Binary Classification |
| **Dataset** | PIMA Diabetes Dataset |
| **Algorithm** | Support Vector Machine (SVM) |
| **Features** | 8 |
| **Records** | 768 |
| **Test Accuracy** | **77.27%** |
| **Environment** | Jupyter Notebook |

### 🔍 What does it do?

Predicts whether a person is:

```text
0 → Non-Diabetic
1 → Diabetic
```

using health-related measurements such as:

**Glucose · Blood Pressure · BMI · Age · Insulin · Pregnancies**

### 🛠️ Built With

`Python` `NumPy` `Pandas` `Scikit-learn` `SVM` `Jupyter`
